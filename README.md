# 🐾 Tamagotchi Pet Shop

Sistema web desenvolvido como projeto acadêmico, utilizando ASP.NET Core MVC, com o objetivo de apresentar produtos e permitir o gerenciamento de um pet shop.

## 🚀 Tecnologias utilizadas

- C#
- ASP.NET Core MVC
- SQLite
- HTML5
- CSS3
- Bootstrap

## 💻 Funcionalidades

- Página inicial com apresentação dos produtos.
- Listagem de produtos disponíveis.
- Cadastro de produtos.
- Edição de produtos.
- Gerenciamento de estoque.
- Área administrativa.

## 🗄️ Banco de dados

O projeto utiliza SQLite para armazenar as informações dos produtos.

## 🎯 Objetivo

Desenvolver uma aplicação web aplicando conceitos de programação, desenvolvimento MVC, integração com banco de dados e criação de interfaces responsivas.

## 👨‍💻 Desenvolvido por

Projeto acadêmico desenvolvido para fins de aprendizado e prática de desenvolvimento web.
